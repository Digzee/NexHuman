# NexHuman

NexHuman is an AI-powered investment platform that combines
evolutionary algorithms, explainable AI and real-time market
analysis to help users build optimized cryptocurrency portfolios.

## Features

- AI Investment Advisor
- Portfolio Optimization
- Explainable AI
- Evolutionary Algorithms
- Cryptocurrency Analytics
- Live Market Data

Vite
Tailwind CSS
Three.js
Django REST
Python
