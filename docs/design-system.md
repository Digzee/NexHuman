# NexHuman Design System

## Brand direction

NexHuman should feel:

- Intelligent
- Human-centred
- Futuristic
- Premium
- Trustworthy

The interface should resemble a modern AI and fintech platform rather than a speculative cryptocurrency trading website.

## Colours

| Purpose | Value |

## Typography

Primary typeface:

- Inter
- System sans-serif fallback

## Components

Initial reusable components:

- Container
- Button
- Navbar
- Hero
- HeroVisual

## Animation principles

Animations should be:

- Smooth
- Deliberate
- Subtle
- Performance-conscious
- Respectful of reduced-motion preferences
